# Example Compositions

Full compositions saved from Stochastic (`.sto`, file format v3). They are
**not** bundled into the app — the in-app **Examples** menu is generated from
[`src/data/examples.ts`](../src/data/examples.ts). To listen to one of these,
open the app and use **File → Open** (or drop the file on the welcome screen's
"Open from File").
